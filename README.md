# Mesokurtic Supply Chain Limited

### *Optimizing Digital Infrastructure & Global Logistics Intelligence*

## 🌐 Overview
Mesokurtic Supply Chain Limited is a logistics firm dedicated to building robust digital infrastructure and supply chain solutions. This platform serves as the official interface for our operations, designed with a focus on accessibility, logical determinism, and high-performance asset delivery.

We aim to bridge the gap in logistics technology, particularly for underserved communities, by implementing high-integrity engineering principles.

## 🏗️ Technical Architecture
This project is a multi-page static web application deployed with a focus on speed and structural integrity.

* **Frontend:** Semantic HTML5 and Responsive CSS3.
* **Deployment:** GitHub Pages (Automated CI/CD via GitHub Actions).
* **Optimization:** Minified assets and relative pathing for zero-failure navigation.
